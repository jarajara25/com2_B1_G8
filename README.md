# ComuII_B1_G8

Práctica 4: Modulación M-PSK y Q-PSK

En esta práctica se implementaron las modulaciones M-PSK y Q-PSK utilizando GNU Radio para analizar las características de la modulación 8-PSK. Se generó una señal binaria, se empaquetaron los bits en grupos de tres para la modulación 8-PSK, y se estudió el impacto del ruido sobre la señal transmitida. Además, se comparó la modulación 8-PSK con Q-PSK en términos de ancho de banda, tasa de símbolos y eficiencia espectral. Los resultados mostraron que, aunque 8-PSK requiere mayor ancho de banda, su tasa de bits puede ser más alta en comparación con Q-PSK bajo ciertas condiciones.
